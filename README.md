## About

Sou CEO da **Luyra Tech** e da **Emma Group**. Minha atuação conecta visão de negócio, estratégia de produto e desenvolvimento de software, com foco em transformar inteligência artificial em ferramentas úteis, compreensíveis e confiáveis.

Trabalho na construção de um portfólio que reúne assistentes de IA, ambientes de agentes, diagnóstico de TI, visualização anatômica e automação editorial. A engenharia é parte central dessa visão: arquitetura clara, interfaces bem resolvidas, controle de permissões e validação das entregas.

Minha abordagem combina desenvolvimento **full stack**, aplicações **desktop** e integração de **LLMs**. Priorizo o ciclo completo de produto: entender o problema, definir o escopo, construir, testar e aprender com o uso real.

### Princípios de liderança

- **Clareza de direção:** conectar cada funcionalidade ao problema que ela resolve.
- **Execução responsável:** distinguir o que foi implementado, validado e planejado.
- **Qualidade como processo:** trabalhar com critérios de aceite e evidências de funcionamento.
- **Autonomia com controle:** manter aprovação humana nas operações que exigem consentimento.
- **Produto como sistema:** considerar experiência, arquitetura e operação na mesma decisão.

### Open to

Parcerias tecnológicas, colaboração em produtos de IA, conversas com engenheiros e designers e oportunidades de desenvolvimento conjunto alinhadas à Luyra Tech e à Emma Group.

## Featured Projects

<details open>
<summary><strong>Emma Apollinaire / Emma Code — Assistente de IA e ambiente de programação</strong></summary>

Assistente desktop com integração de modelos, memória e ferramentas. O ambiente Emma Code conecta conversa, workspace e execução de tarefas de programação.

| Dimensão | Detalhes |
| :--- | :--- |
| Stack | Electron · TypeScript · Supabase · NVIDIA integrations · Ollama |
| Scale | Gateway de IA, roteamento de modelos, registro de capacidades e orquestração de ferramentas. |
| Performance | Streaming, cancelamento e limites de execução; sem benchmark público de latência. |
| Security | Fronteira de workspace, classificação de risco, aprovação e logs com redação de segredos. |
| Impact | Reúne assistência, contexto e ferramentas de programação em um aplicativo desktop. |
| Repository | Código e documentação pública serão vinculados quando disponibilizados. |

**Decisão de engenharia:** evoluir o gateway e o orquestrador existentes, preservando os controles de execução ao ampliar as ferramentas.

**Evidência registrada em setembro de 2026:** 939 testes, 1.000 execuções de soak e smoke com provedor real no fechamento do hardening. Esses resultados representam o checkpoint local registrado.

</details>

<details>
<summary><strong>Vortex — Ambiente desktop para equipes de agentes de IA</strong></summary>

Aplicação educacional para criar agentes especializados e coordenar trabalho em equipe, com console de execução e acompanhamento das atividades.

| Dimensão | Detalhes |
| :--- | :--- |
| Stack | Electron · TypeScript · React · esbuild · NVIDIA integrations |
| Scale | Sete papéis iniciais, criação de agentes, missões em equipe, handoffs e memória por agente. |
| Performance | Telemetria de tokens e latência, orçamentos de execução e streaming. |
| Security | SecretManager e fila de aprovação para escrita e execução. |
| Impact | Torna visíveis a coordenação, as ferramentas e os resultados de agentes especializados. |
| Repository | Código e documentação pública serão vinculados quando disponibilizados. |

**Decisão de engenharia:** derivar o status das missões de evidências do executor e manter os limites de execução explícitos. A existência de uma ferramenta precisa ser acompanhada de prova de uso e resultado.

</details>

<details>
<summary><strong>Emma Desk — Investigação e diagnóstico de TI para Windows</strong></summary>

Aplicação desktop que organiza o fluxo de investigação, diagnóstico, plano de reparo, autorização e validação do resultado.

| Dimensão | Detalhes |
| :--- | :--- |
| Stack | Electron · TypeScript · React · PowerShell · Windows |
| Scale | Nove telas e dez categorias de diagnóstico verificadas no checkpoint local. |
| Performance | Limite de três processos PowerShell e prevenção de polling sobreposto. |
| Security | Reparos sujeitos a aprovação; credencial protegida pelo Windows. |
| Impact | Estrutura a investigação técnica e apresenta ações de reparo ao usuário. |
| Repository | Código e documentação pública serão vinculados quando disponibilizados. |

**Evidência registrada:** 288 testes e validação de build e diagnóstico local. A inferência NVIDIA permaneceu indisponível para a conta no checkpoint; os fluxos de diagnóstico local foram verificados separadamente.

</details>

<details>
<summary><strong>Anatomic Hood — Exploração anatômica interativa em 3D</strong></summary>

Aplicação desktop com atlas anatômico, navegação por estruturas e mecanismos demonstrativos de investigação clínica.

| Dimensão | Detalhes |
| :--- | :--- |
| Stack | Electron · Vite · React Three Fiber · Three.js · Zustand · BodyParts3D |
| Scale | Atlas registrado com 2.234 malhas e aproximadamente 2,4 milhões de triângulos. |
| Performance | Organização de geometria para reduzir custo de renderização; FPS não medido. |
| Security | Dados clínicos demonstrativos; autenticação e prontuários fora do escopo registrado. |
| Impact | Permite explorar estruturas anatômicas em uma interface desktop em português. |
| Repository | Código e documentação pública serão vinculados quando disponibilizados. |

**Decisão de engenharia:** preservar os identificadores utilizados pelas regras ao incorporar a geometria do atlas. O motor demonstrativo utiliza um score de compatibilidade, sem alegação de probabilidade diagnóstica ou validação clínica.

</details>

<details>
<summary><strong>Emma Jornal — Pipeline de pesquisa e produção editorial</strong></summary>

Aplicação web para pesquisa de notícias esportivas, agrupamento de fatos, decisão editorial, geração de artes e organização da fila de publicação.

| Dimensão | Detalhes |
| :--- | :--- |
| Stack | Next.js · React · TypeScript · Prisma · SQLite · Satori · Resvg |
| Scale | Doze fontes RSS/Atom e treze templates de arte no checkpoint registrado. |
| Performance | Geração local de artes, fila persistente e agrupamento de notícias. |
| Security | Verificação de números, crédito de fontes e publicação dependente de credenciais oficiais. |
| Impact | Organiza pesquisa, produção e revisão para o projeto editorial Placar Cego. |
| Repository | Código e documentação pública serão vinculados quando disponibilizados. |

**Princípio editorial:** verdade, fonte, relevância, velocidade, qualidade e engajamento, nessa ordem. O checkpoint registrado inclui 338 testes; publicação externa depende da configuração da API oficial da Meta.

</details>
